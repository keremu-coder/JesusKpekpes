Stereo is the default. The game can stay at 2 channels. Secure Boot stays on.

Open the app. Three steps.

1. Confirm the headphones.
2. Hear a step, then a shot. That is the same mix Turn on writes.
3. Turn on. Press Yes if Windows asks.

Drop is the short step. Well is the same step with the room pushed down. 7.1 is optional, and only if the headphones are set to 7.1.

Equalizer APO must already be installed, and it must be turned on for those headphones. The app says so if it is not. Your own driver waits until it is signed.
