Jesus Kpekpes

Download JesusKpekpes-Setup.exe from the Releases page. This source folder is not the program.

https://github.com/keremu-coder/JesusKpekpes/releases/latest

This build is not signed. Windows SmartScreen will warn you. Choose More info, then Run anyway, then Yes when Windows asks for Administrator. There is no auto-update. An updater on an unsigned Administrator program would be a bad idea.

Run JesusKpekpes-Setup.exe to install. It appears in the Start menu and in Windows Settings, Apps. Uninstall there puts the PC changes back and leaves audio as it is. Or extract the zip and run JesusKpekpes.exe from inside it. Keep the pc folder and JesusKpekpesTune.dll beside the exe.

Press Get the audio programs. For Equalizer APO, press Download + open. The file is checked against a pinned SHA-256, and only then is the vendor setup opened for you to click through. A file that does not match is deleted and never opened. ReaPlugs has the same button. HeSuVi, ReaPlugs and VoiceMeeter are not turned on.

Audio tune
Pick the headphones. Choose Nova Pro only for the Arctis Nova Pro on the small USB adapter. Leave Sonar off, and leave the GameDAC equalizer off. Do not also run Insured Audio or Rara, or they stack. Push Footstep hit to the right. Leave 7.1 off unless Windows shows 8 channels. Press Turn on. Drop and Well are still there and are unchanged.

Call of Duty settings
Close the game first. Press Apply. That sets Reflex to On + boost and the in-game cap to one under the monitor. A 200 Hz panel gets 199. Undo puts the original file back.

Optimize the PC
Press What will change and read it before Optimize PC and controller. If the monitor is below the highest rate Windows already lists at this resolution, Optimize raises it. Undo is on that same window. Audio is not touched. Name the hitch watches for about 20 seconds and prints a name. It does not change a setting.

Monitor and frames
Start the game and stay in a match. Press Record before and leave it for one minute. Change what you want to change. Press Record after the same way. The window prints average FPS, 1% low and 0.1% low from the displayed frames. If it says nothing was measured, the game was not seen. Do not treat a blank as zero.

Startup menu
Tick only the programs that should not open with Windows, then press Turn ticked ones off. They stay installed. Windows Security and this program are not in the list. Undo on the PC window turns the rest back on.

Test on your own PC
Press Check this PC and copy the whole text.
Press Network check and copy the whole text.
While the game is open, press Name the hitch and copy the name. If it says the trace was not given, copy that too.
Those three pastes are the test. A guide cannot invent them.

Compare with Rara
Use the same clip, the same volume, and the same headset.
Turn this tune off and leave Rara on. Open Sound check. Press Record 10 seconds while the clip plays.
Turn Rara off. Open Audio tune, choose the mix, press Turn on. Press Record 10 seconds on the same clip.
Copy both blocks, including the lines that start with Second minus first.
Those numbers are the comparison. They are not a lab meter and they are not LUFS. If both runs match almost exactly, the recording missed the tune. Do not treat that as a result.

The plug-in
